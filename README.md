# Ashes landing page

A full-screen, responsive Ashes hero page built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

The background video is bundled in `public/mainframe-hero.mp4`. The Helvetica Now Display font stylesheets load from the URLs provided in the brief.

## Publish with GitHub Pages

In the repository settings, open **Pages** and set the publishing source to **GitHub Actions**. The workflow in `.github/workflows/deploy.yml` builds and publishes the site whenever the `AI` branch is updated.
